## 履歴が表示されない

```text

manifest.json、インストール済みのプラグインファイル、data.json の gitExecutable と repositoryRoot を確認してください。デスクトップ版 Obsidian 1.13 以降か、Git が使えるか、サイドバーのメッセージ全文を私に聞いてください。Git がない、リポジトリがない、コミットがない、ノートが未追跡または無視対象、ステージ済みで未コミット、検出したリポジトリの外にある、という場合を区別してください。初期化、コミット、ステージング、除外ルールの編集はしないでください。Git の準備が足りなければ、プラグインの不具合とはせず、私に必要な操作を説明してください。
最後に、私がコミット済みと分かっているノートを開き、時計のアイコンからバージョンを選び、「Compare with current」を押します。そのノートの履歴と比較が表示されることを確認します。準備が足りなければ、その問題を報告し、「See an example (no repository needed)」で 3 つのデモ版が開くことを確認します。デモの成功だけで実際の履歴も直ったとは判断しないでください。
```


```text
メッセージ全文と、プレビューを開いた後や復元した後に編集したかを私に聞いてください。プラグインの復元前の照合と、最大 12 回分の取り消し履歴を確認してください。ノートが変わったときに止まるのは正常です。保護処理、設定、取り消し履歴を残し、強制的な書き込みや data.json のリセットはしないでください。
ノートを変更せずに確認するため、私が比較と復元プレビューを開き直し、指定したノートの現在の内容が反映されることを確認します。「See an example (no repository needed)」でメモリ上の復元を試し、デモだけが更新され、実際のノートは変わらないことを確認します。変更検出を修正した場合はメモリ上の入力で検証し、未変更なら進められ、変更済みなら必ず停止することを確認してください。現在の編集が取り消しを妨げる場合は、正常な制限として報告してください。
```
